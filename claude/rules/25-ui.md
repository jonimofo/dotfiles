# UI baseline

Applies to every project with a user interface. Project design docs and tokens override the detail.

- Readable contrast everywhere: no muted or low-contrast text for content the user must read.
  Chart text and labels follow the theme.
- Tablet landscape is a target for every page. Hover-only reveals (opacity 0 until hover) are
  forbidden: action buttons render at full opacity.
- Every table with selectable rows supports keyboard navigation; every sortable or filterable
  page remembers its filters.
- Dialogs, selects, tabs and badges come from the project's shared component library, never
  hand-rolled. Status is a colored dot plus plain text unless the project says otherwise.
- Layout changes start with an ASCII mockup validated by the user (see `10-workflow.md`), and
  every mockup includes the tablet view.
