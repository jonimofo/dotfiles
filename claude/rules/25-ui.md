# UI baseline

Applies to every project with a user interface. Project design docs and tokens override the detail.

- Readable contrast everywhere: no muted or low-contrast text for content the user must read.
  Chart text and labels follow the theme.
- Dialogs, selects, tabs, badges and tables come from the project's shared component library or
  design tokens, never hand-rolled or hardcoded.
- Layout changes start with an ASCII mockup validated by the user (see `10-workflow.md`), at the
  screen sizes the project targets.
- Interactive elements are reachable and visible without hover: no action hidden until mouse-over.
